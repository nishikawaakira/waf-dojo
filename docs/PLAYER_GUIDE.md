# WAF Dojo プレイヤー向けのはじめ方

WAF Dojo は、本物の AWS WAF にルールを設定して、実際に届く攻撃を防ぐ練習をするゲームです。攻撃をたくさんブロックするほど、正常なお客様を誤ってブロックしないほど高得点です。

## 管理者から受け取るもの

| もの | 使いみち |
|---|---|
| ゲーム画面の URL | あなた専用の URL です。**他の人に教えないでください** |
| AWS コンソールのログイン先・ユーザー名・パスワード | WAF のルールを設定するのに使います |

## はじめ方

### 1. ゲーム画面を開く

受け取った URL をブラウザで開きます。右上にあなたの名前が表示されていれば準備完了です。画面の右下にいる柴犬の「まもりん」が、次に何をすればよいか教えてくれます。

> 同じパソコンで複数の人が遊ぶときは、人ごとに別のブラウザかシークレットウィンドウを使ってください。

### 2. AWS コンソールにログインする

1. ログイン先の URL を開き、ユーザー名とパスワードを入力します。
2. 右上のリージョンを **アジアパシフィック (東京)** にします。
3. ゲーム画面の「AWS WAF コンソールを開く」から、WAF の画面を開きます。
4. 一覧の中から **自分の名前の Web ACL** (`wafdojo-<あなたの名前>`) を開きます。

> 新しい WAF コンソールでは、メニュー名が「Protection packs (web ACLs)」になっていることがあります。

### 3. チュートリアルから始める

ロビーの「チュートリアル」を上から順に進めます。

1. 問題を開いて、「これから来る攻撃」と「設定手順」を読みます。
2. 手順のとおりに、自分の Web ACL にルールを設定します。
3. **30〜60 秒待ってから**「攻撃開始」を押します (ルールが反映されるまで時間がかかります)。
4. 結果と内訳を見て、すり抜けた攻撃や誤ってブロックした通信がないか確認します。

6 本のチュートリアルをすべて 70 点以上でクリアすると、次のモードが解放されます。

| モード | 内容 |
|---|---|
| ゲームモード | 手順なし。条件の組み合わせや例外などを自分で考えます |
| 脆弱性対応ラボ | 「〜という脆弱性が出ました」という情報から自分でルールを作ります (Level 1〜4) |
| 運用演習 | まず「偵察する」(採点なし) で Count のルールの効果をログで確かめてから本番に臨みます |
| 実戦テスト | 攻撃の例も模範解答もない本番さながらのテストです |

## 知っておくと便利なこと

- **スコア** = 100 × 攻撃のブロック率 × (1 − 誤ブロック率)。80 点以上でその問題を「こなした」ことになります。
- **ヒント** を見ると、その問題のスコアが ×0.8 になります。
- **模範解答** は、一度挑戦すると見られます (実戦テストを除く)。コンソールの Rule JSON editor にそのまま貼り付けられます。
- **IP セット・正規表現パターンセット** を作るときは、名前を `wafdojo-<あなたの名前>-` で始めてください。それ以外の名前では作れません。
- 前に作ったルールは残ったままです。**こなした問題のルールは削除**しておくと、他の問題で思わぬ誤ブロックが起きにくく、ルールの容量 (WCU) の上限にも当たりにくくなります。
- 最初の数件だけすり抜けたときは、ルールの反映待ちの可能性があります。少し待ってもう一度挑戦してください。
- まもりんをクリックすると、ワンポイントを教えてくれます。× で隠せます。
- 段位や実績を集めて、全問こなすと **WAF スペシャリスト** に認定されます。
- WAF のログは、CloudWatch の Logs Insights でロググループ `aws-waf-logs-wafdojo-<あなたの名前>` を選ぶと調べられます。
- **CloudFront を使う問題** (ラボ Level 4 の「CloudFront: 16 KB の壁を 64 KB まで広げる」) だけは、攻撃が CloudFront に届きます。設定するのは CloudFront 用の Web ACL `wafdojo-<あなたの名前>-cf` で、WAF コンソールのリージョンは **Global (CloudFront)** を選びます。ログはバージニア北部 (us-east-1) のロググループ `aws-waf-logs-wafdojo-<あなたの名前>-cf` にあります。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 「自分専用の URL から開いてください」と出る | 管理者から受け取った URL から開き直してください |
| Web ACL が見つからない | リージョンが東京になっているか確認してください |
| IP セットを作れない | 名前が `wafdojo-<あなたの名前>-` で始まっているか確認してください |
| ルールを追加できない (容量のエラー) | こなした問題のルールを削除してください |
| 「別の攻撃が実行中」と出る | 前の攻撃が終わるまで待ってください |
